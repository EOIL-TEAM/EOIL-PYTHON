# eoil

The official Python SDK for [EOIL](https://eoil.ltd) — hardware-accelerated optimisation as an API.

```bash
pip install eoil
```

Full documentation: [eoil.ltd/docs](https://eoil.ltd/docs)

> **Note:** This repository is automatically synced from the EOIL monorepo on each SDK release. Do not open pull requests here — raise issues only.
